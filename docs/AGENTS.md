# Lavista design-system instructions

Before creating or restyling any UI for this project, read:

- `docs/design-system/lavista.md`
- `docs/design-system/lavista.tokens.json`

The Lavista design system is extracted from the current public website. Treat
the documented tokens, typography, surfaces, interaction patterns, responsive
rules, and accessibility guidance as the source of truth for future UI work.

Do not change existing screens merely by reading these files. Apply the system
only when the user explicitly asks for a screen change or approves an
application of the design system.
